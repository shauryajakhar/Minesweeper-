# Minesweeper in C

A simple Minesweeper game written in C as a personal programming project.

## About

This project is my implementation of the classic Minesweeper puzzle game. The goal is to uncover all safe cells without triggering a mine.

I'm building this project to practise C programming, problem-solving, loops, arrays, and game logic.

## Features

- Console-based game
- Board represented using a 2D array
- Mine placement and cell-reveal logic

## Built With

- C
- Standard C library (`stdio.h` and other headers as needed)
- GCC compiler

## Getting Started

### Prerequisites

Install a C compiler such as GCC.

### Compile

Open a terminal in the project directory and run:

```bash
gcc minesweeper.c -o minesweeper
```

### Run

On Windows:

```bash
./minesweeper.exe
```

On Linux or macOS:

```bash
./minesweeper
```
